# Calculadora Simples

Este projeto é uma calculadora web simples desenvolvida com HTML, CSS e JavaScript. Ela permite realizar operações básicas de forma intuitiva diretamente no navegador.

## Funcionalidades principais

- Adição, subtração, multiplicação e divisão
- Inserção de números e operadores via botões
- Limpeza do display com o botão C
- Remoção do último caractere com o botão de voltar
- Exibição do resultado ao pressionar o botão =
- Tratamento de erros para entradas inválidas

## Como usar

1. Abra o arquivo index.html em seu navegador.
2. Use os botões para inserir números e operadores.
3. Pressione = para calcular o resultado.
4. Use C para limpar o display e voltar para apagar o último caractere.

## Estrutura do projeto

- index.html: estrutura da interface da calculadora
- style.css: estilos visual da aplicação
- main.js: lógica de funcionamento da calculadora

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
